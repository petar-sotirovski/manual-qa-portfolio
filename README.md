## 📌 Project Overview

This repository documents a full manual QA pass on my personal portfolio website. Rather than testing a hypothetical or sample application, I tested my own live site — meaning every result here is real and independently verifiable.

The goal of this project was to apply core QA methodology (SDLC/STLC principles, functional testing, UI/responsiveness testing, cross-browser testing, and accessibility checks) to a real product, and to practice the full bug lifecycle: from writing structured test cases through to filing clear, reproducible bug reports.

## 🗂️ Test Categories Covered

- **Navigation & Functional Flow** — nav links, anchors, external links, broken link checks
- **Forms** — validation logic, empty submission handling, success states
- **Responsiveness** — mobile, tablet, and 4K/UHD layout behavior
- **Cross-Browser Compatibility** — rendering consistency across major browsers
- **Accessibility** — keyboard navigation, focus states, image alt text
- **Performance & Technical Health** — load time, console errors, HTTPS, SEO/meta basics
